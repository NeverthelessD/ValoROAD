INSTALL GUIDE · 무료 애플 ID 로 내 아이폰에 설치하기 (처음 한 번 약 10분)
FIRST TIME · 처음 한 번
01

파일 풀기UNZIP

맥 받은 ValoROAD-iPhone.zip 을 더블클릭해 풀고, 나온 ValoROAD-iPhone 폴더를 문서 폴더에 옮겨 두세요. 7일마다 다시 쓰니 지우지 마세요.

02

Xcode 로 열기OPEN

맥 폴더 안의 ValoROAD.xcodeproj (파란 아이콘)를 더블클릭해요. Xcode 가 열리고 왼쪽에 파일 목록이 보이면 준비 끝이에요.

03

애플 ID 넣기ACCOUNT

맥 위 메뉴 Xcode › Settings… › Apple Accounts(또는 Accounts)에서 왼쪽 아래 + › Apple Account 를 눌러 평소 쓰는 애플 ID로 로그인해요. 무료예요.

04

팀 고르기SIGNING

맥 왼쪽 맨 위 파란 ValoROAD 클릭 › 가운데 Signing & Capabilities 탭 › Team 에서 내 이름 (Personal Team) 을 골라요. 빨간 오류가 없으면 통과예요.

05

아이폰 연결CONNECT

아이폰 케이블로 맥에 연결하고 “이 컴퓨터를 신뢰” › 암호 입력. 그다음 설정 › 개인정보 보호 및 보안 › 개발자 모드를 켜고 재시동해요. (메뉴가 안 보이면 06을 한 번 한 뒤 다시 봐요)

06

설치 ▶RUN

맥 Xcode 맨 위 가운데에서 내 아이폰 이름을 고르고 왼쪽 위 ▶ 를 눌러요. 1~3분 뒤 아이폰에 ValoROAD 아이콘이 생겨요. 처음엔 시간이 좀 더 걸려요.

07

개발자 신뢰TRUST

아이폰 처음 열 때 “신뢰하지 않는 개발자” 창이 뜨면 설정 › 일반 › VPN 및 기기 관리 › 내 애플 ID › 신뢰를 눌러요. 그다음 앱을 다시 열어요.

08

계정 추가SIGN IN

아이폰 알림은 허용. 상점 화면의 계정 추가를 누르면 라이엇 공식 로그인 화면이 열려요. 로그인 상태 유지를 켜고 로그인하면 끝! 비밀번호는 앱이 보지 않아요.

EVERY 7 DAYS · 7일마다
▶
아이폰을 맥에 연결하고 Xcode 에서 ▶ 한 번

무료 애플 ID 로 설치한 앱은 7일 동안 열려요. 설정 화면의 APP PASS 막대에 남은 날이 보이고, 하루 전에 알림이 와요.
다시 설치해도 계정 · 위시리스트 · 로그인은 그대로 남아요. 기간이 지나 앱이 안 열려도 ▶ 만 누르면 다시 돼요.

TIPS · 이럴 땐
  • 케이블 없이 하려면: 한 번 연결된 상태에서 Xcode 메뉴 Window › Devices and Simulators › 내 아이폰 › Connect via network 를 켜 두면, 같은 와이파이에서 케이블 없이 ▶ 로 설치돼요.
  • 04에서 “Failed to register bundle identifier” 가 뜨면: 바로 위 Bundle Identifier 끝에 숫자를 붙여(예: …iphone.mine2) 바꾸면 돼요.
  • 06에서 “Developer Mode disabled” 가 뜨면 05의 개발자 모드를 켜 주세요. “Untrusted Developer” 는 07을 하면 돼요.
  • 무료 애플 ID 는 일주일에 앱 3개까지 설치할 수 있어요. 나중에 유료(TestFlight)로 바꿔도 계정은 이어서 써요.
  • 앱이 이상하면 설정 › 진단 정보 보기 › 복사 를 눌러 그대로 보내 주세요.
