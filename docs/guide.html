ValoROAD
STORE CHECKER · 발로란트 상점 확인 앱 · 사용 가이드
HOW TO USE · 이렇게 써요
01

처음 열기OPEN

ValoROAD.app 을 응용 프로그램 폴더로 옮긴 뒤 열어요. 처음 한 번 “확인되지 않은 개발자” 창이 뜨면 Control 키를 누른 채 앱을 클릭 → 열기를 눌러 주세요.

02

계정 추가ADD ACCOUNT

왼쪽 빈 자리를 누르면 라이엇 공식 로그인 창이 열려요. 거기서 직접 로그인하고 ‘로그인 상태 유지’를 켜 주세요. 최대 3개까지 저장돼요.

03

계정 바꾸기SWITCH

왼쪽 계정을 누르면 로그아웃 없이 그 계정의 오늘의 상점 · 번들 · 밤시장이 바로 떠요. ⌘1 · ⌘2 · ⌘3 으로도 바꿀 수 있어요.

04

위시리스트 알림WISHLIST

상점 카드의 하트나 위시리스트 화면에서 스킨을 담아 두면, 3개 계정 중 어디든 그 스킨이 뜰 때 맥 알림으로 알려줘요.

비밀번호는 저장하지 않아요ValoROAD는 비밀번호를 보지도 저장하지도 않아요. 로그인 뒤 받은 ‘로그인 열쇠’만 맥 키체인에 잠가 두고, 이 맥 밖으로 보내지 않아요.
CAUTION · 꼭 알아 두세요
  • 확인 전용 앱이에요. 구매는 게임 안에서 해 주세요.
  • 상점은 매일 오전 9시에 바뀌어요. 알림은 ValoROAD 가 Dock 에 켜져 있을 때 확인하고, 꺼져 있었다면 다음에 켤 때 알려줘요. 처음 켤 때 ‘알림 허용’을 눌러 주세요.
  • 라이엇 보안 정책 때문에 가끔(보통 몇 주에 한 번) 그 계정만 다시 로그인해야 해요.
  • 라이엇이 연결 방식을 바꾸면 잠시 상점이 안 보일 수 있어요. 새 버전이 나오면 앱이 알아서 받아요.
  • 창을 닫아도 앱은 Dock 에 남아요. 완전히 끄려면 ⌘Q. 문제가 생기면 설정 › ‘진단 정보 보기’ 내용을 보내 주세요.
  • ValoROAD는 Riot Games가 만들거나 보증한 앱이 아니에요. 게임 이름과 아이템 이미지는 Riot Games 의 자산이에요.
